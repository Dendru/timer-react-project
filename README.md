# ⏱️ Interactive Timer

Интерактивный таймер на **React + TypeScript** с адаптивным интерфейсом и оптимизацией для мобильных устройств.

Проект создан в рамках практики React и AI-assisted разработки. Первоначальный прототип был реализован с помощью **Cursor**, после чего я самостоятельно тестировал и дорабатывал проект, в том числе оптимизировал его работу на мобильных устройствах.

После генерации я самостоятельно тестировал приложение, анализировал поведение интерфейса и дорабатывал код.

## ⚙️ Installation

Клонировать репозиторий:

```bash
git clone https://github.com/Dendru/timer-react-project.git
```

Перейти в директорию проекта:

```bash
cd timer-react-project
```

Установить зависимости:

```bash
npm install
```

Запустить development server:

```bash
npm run dev
```

После запуска приложение будет доступно по адресу:

```text
http://localhost:5173
```

## 📦 Build

Создать production-сборку:

```bash
npm run build
```

Запустить production preview:

```bash
npm run preview
```
